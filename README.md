# Diplom
Веб-приложение на PHP и MySQL: образовательная платформа с тестами, материалами по профессиям, статьями и личным кабинетом пользователя.
## Возможности
- главная страница с каруселью тестов и блоком статей;
- прохождение тестов, просмотр результатов и прогресса;
- каталог профессий и текстовые статьи;
- регистрация, вход в аккаунт, профиль (в том числе аватар), сохранение прогресса;
- симуляторы и игровые задания (в т.ч. режимы с уровнями);
- таблица лидеров;
- админ-панель: управление контентом, вопросами и связанными сущностями.
## Стек
- PHP
- MySQL (mysqli)
- HTML, CSS, JavaScript на стороне клиента
## Установка
1. Склонируйте репозиторий или скопируйте файлы в каталог веб-сервера (например, Open Server, локальный домен или `localhost`).
2. Создайте базу данных MySQL и импортируйте SQL-скрипты из папки `sql/` и при необходимости корня проекта (`*.sql`).
3. В `config.php` укажите параметры подключения к БД (хост, имя базы, пользователь, пароль).
## Запуск
Откройте в браузере корень сайта (например, `http://localhost/.../` или ваш виртуальный хост).
Для входа в админку создайте запись администратора через соответствующие SQL-скрипты и используйте форму входа из раздела администрирования.
